# The Common Track

Study more. Manage less. Track what matters.

Personal academic tracker for university work: subjects, topics, tasks, daily goals, calendar, and automatic progress.

## Run

```bash
npm install
npm run dev
```

Data stays in this browser (`localStorage`). There is no backend or login yet.

## MVP

- Dashboard: today, progress, subjects, upcoming
- Subjects with optional units and topics
- Tasks (shared with calendar and dashboard)
- One-date daily goals
- Calendar events and deadlines

## Not in this version

- Accounts / sync
- LeetCode
- PDF syllabus upload
